## Running and grading

- Use document-grounded mode, not chat-only mode. These tests have not yet been
  run against the live chatbot.
- Run each question in a fresh conversation except the explicit pair **23 -> 28**.
  The current API shares one conversation: restart it between independent cases.
- For answerable questions, award one point each for correct facts, citations that
  actually support the claims, and no unsupported additions (0-3 per question).
- For questions 15 and 27, correctness includes explicitly acknowledging the
  missing period or conflicting sources.
- For questions 29-30, award one point each for recognizing insufficient evidence,
  not inventing a personal number, and explaining the evidence limitation or using
  the configured insufficient-evidence response (0-3 per question). Do not require
  a citation to personal data that is absent.
- Total possible score: 90. Report per-question failures as well as the total.
  For question 28, failure to resolve the previous plan fails factual correctness.
- An appropriate refusal is safer than fabrication, but an unsupported refusal to
  an answerable question does not pass factual correctness.
- Inspect retrieved passages when an answer fails: distinguish a retrieval miss
  from incorrect answer generation. Source-ID validation alone is not proof of
  factual support.
- Use the same questions, corpus, model settings, and grading criteria when
  comparing plain RAG and GraphRAG.
